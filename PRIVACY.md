# Privacy Policy for WhatIfAutomation

**Last Updated:** November 13, 2026

WhatIfAutomation ("the App") is a private, internal automation tool created solely for personal content scheduling and publishing on Instagram.

## 1. Data Collection and Usage
- The App does not collect, store, sell, or share personal data from third-party users or the general public.
- The App accesses Instagram Graph API credentials solely to publish automated video content to the developer's own authorized Instagram Creator account (`@chronological.whatifs`).

## 2. Data Storage and Security
- Access tokens and account identifiers are stored locally in encrypted or restricted environment files on the developer's private machine.
- No user data is transmitted to external third-party analytics or advertising services.

## 3. Data Deletion
- Because no external user data is collected or stored, no user data retention occurs. Access tokens can be revoked at any time via Meta Account Settings under Apps and Websites.
